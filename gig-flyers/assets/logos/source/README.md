# Official logo sources (Lindsey Lane Band)

Drop **PNG exports** here, then run from `gig-flyers/`:

```bash
python3 scripts/install_band_logos.py
```

| File | Description |
|------|-------------|
| `stack-on-white.png` | Black ink lockup on white (turquoise brush) — dark logo for light flyers |
| `stack-on-black.png` | White ink lockup on black (red brush) — light logo for dark flyers |
| `circle-on-black.png` | Circular badge (white type, red brush on black) — wild poster corner badge |

Legacy fallback: `IMG_8015.png` / `IMG_8016.png` at **repo root** (nested-L lockup).

Installed outputs live in `../` (`lindsey-lane-band-dark.png`, `-light.png`, `-circle.png`, etc.).
